# zno-bot-v2.0
Статус: перестав працювати через зміни на сайті zno-osvita.
Опис: Телеграм бот для підготовки до НМТ через випадково підібрані питання з сайту https://zno.osvita.ua/
# Функціонал:
1) Вибір предмету(на останній апдейт було реалізовано 4 предмети, проте їх просто додавати вказавши конфігурацію в файлі subjet_list.py) <img width="413" height="145" alt="image" src="https://github.com/user-attachments/assets/0136a86b-54bc-444e-8a5b-9d4bb78baf57" />
2) Перегляд статистики. Бот розрахований на особисте використання, тож вся інформація зберігається в локальному файлі stats.json.<img width="453" height="110" alt="image" src="https://github.com/user-attachments/assets/3b25c72b-a5ab-465b-b3f3-acbe590262fb" />

3) Отримання скріншоту(для збереження форматування математичних виразів) випадкового завдання з випадковими варіантами відповідей. <img width="1042" height="546" alt="image" src="https://github.com/user-attachments/assets/6c71ca22-2ea8-443b-85b3-1564f6f96905" />

4) Перегляд пояснення. Раніше на сайті пояснення було сховане прямо в html код сторінки, тож отримати його було досить просто.
